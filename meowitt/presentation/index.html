CPSC 332 Final Project Presentation

Meowit

Charles Bennington

Fri Dec 6 2024

Meowit, a forum posting app, modeled after reddit.

Functional Requirements:

  1. Users must be able to create an account (front + back)
  2. Users must be able to login to an account (front + back)
  3. Users must be able to create posts with a maximum of 1000 characters. (font + back)
  4. Users must be able to post pictures in posts (front + back)
  5. Users must be able to apply a title to their post with a maximum of 50 characters (front + back)
  6. Users must be able to apply tags to posts (front)
    • Example: “cute cat photo”, “Orange cat”, “Silly cat”
  7. Users must be able to maintain and increase their current karma scores (front)
  8. Users must be able to view a user profile (front + back)
  9. Users must be able to view their current Karma (front)
  10. Users must be able to earn badges and awards from karma (front)
  11. Users must be able to search for posts by name (front + back)
