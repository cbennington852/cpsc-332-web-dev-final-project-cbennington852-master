## Meowit
The goal of this project is to create a similar product to reddit, a forum posting website, where users can create an account, login, and post things. This would also have a ‘karma’ system. This website is for specifically talking and discussing cats, their maintenance, and their overall care.
Users would be able to login and anonymously discuss petcare and other things, such as pet insurance. Users will be able to ‘tag’ their posts, so that those posts have some sort of organization.



## Overview

Meowit is a web application built using React for the front end and Node.js for the back end. It allows users to:
- Create an account and log in.
- Post questions, insights, or information anonymously.
- Tag posts for organization.
- Receive "karma" points based on the community's interaction with their posts.

The application promotes a safe, organized space for cat enthusiasts to discuss topics related to feline care and maintenance.

## Installation

To install the necessary dependencies using npm:

1. Ensure you have [Node.js and npm](https://nodejs.org/) installed.

2. Navigate to your project directory:
   ```bash
   cd meowitt
Install all required packages:
`npm install`

Also navigate to the server directory;
`cd server`
and install all of the server specific dependencies using
`npm install`

3. make sure you have MongoDB Compass installed, using MongoDb compass you can import the current saved data.
   In the "documentation" folder you will see two json files, each of which can be used to import the data, you can import them using
   the mongoDB app.

This will install all dependencies listed in the package.json file, setting up your project for development.

## Usage / running the website
Navigate to the Meowitt directory.

1. Starting the node.js server
   -navigate to the server directory
   `node index.js` to start backend server  (required)
2. Starting the react Webpage
   -navigate to meowit directory (in a new terminal tab)
   -type `npm start`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

The page will reload when you make changes.\
You may also see any errors in the console.
